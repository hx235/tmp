Noise Scale · Delta Loss per Step Verification

ΔL at each step: full-batch vs mini-batch

Same data, same starting weights, optimal step size at every step. We plot the actual change in training loss ΔLt = Lt+1 − Lt and the change predicted by the noise-scale theory. For this task the theory is exact, so the two should line up. Then we turn that into an exchange rate: how many mini-batch steps it takes to buy the loss drop of one full-batch step, at every step of training.

Optimal step size εopt(B) = |G|² / ( GTHG + tr(HΣ)/B ) — Eq 2.6
Predicted improvement ΔLopt(B) = −½|G|⁴ / (GTHG + tr(HΣ)/B) — Eq 2.5 at optimum
Noise scale Bnoise = tr(HΣ) / GTHG — Eq 2.8
Average noise scale ≈ —

The learning rate is not a slider — it is derived at each step from the current gradient, curvature, and noise. Full-batch uses ε = |G|² / GTHG. Mini-batch divides by (1 + Bnoise/B), so it must take a smaller step when the gradient is noisy. This automatically gives the largest possible drop in loss for that batch size.

Smaller B means noisier gradient. Larger B is closer to full-batch.

The exchange rate · steps per step

How many mini-batch steps buy the same loss drop as one full-batch step?

Take the loss drop ΔL that full-batch GD achieves at step t. Starting from the exact same weights, how many mini-batch steps does SGD need to bank that same drop? The noise-scale theory says 1 + Bnoise/B, and nothing else.

Why there are two measured lines. The pink line divides GD's loss drop at step t by the average loss drop of a single mini-batch step taken from the same weights — that is exactly the quantity 1 + Bnoise/B predicts, so it should sit on the dashed line. The grey line actually runs SGD from those weights until the loss has fallen that far and counts the steps. It lands slightly higher, because inside the catch-up window the gradient keeps shrinking, so step 2 of the window buys a little less than step 1 did — a compounding effect the single-step ratio does not include.

Setup: 256 training examples, 12 parameters, linear model with squared error. Feature variances span a factor of 200, so the curvature is ill-conditioned and full-batch GD needs tens of distinct steps rather than a handful. Curvature H is constant, so the second-order prediction is not an approximation — it is exact. Gradient G, curvature H, and the full D×D gradient covariance Σ are computed over all 256 examples at each step, and Bnoise = tr(HΣ) / GTHG is formed from that explicit Σ — no shortcut. Step size is chosen at each step to give the biggest expected drop (Eq 2.6); for full-batch that is the exact line-search minimiser, so no stability cap is needed. Both methods start from the same weights. Mini-batches are drawn with replacement, which is the sampling assumption behind Σ/B in the paper. Median noise scale is the middle value of Bnoise over the first 30 steps.
